# 天气指数 (Indices)

来源: https://dev.qweather.com/docs/api/indices/

天气生活指数：根据气象要素计算，直观反映天气对人类活动的影响。中国及全球城市均支持，各类型覆盖范围见下表（部分仅中国）。

## 天气指数预报

https://dev.qweather.com/docs/api/indices/indices-forecast/

```
GET /v7/indices/{days}?type={ids}&location={id|经度,纬度}
```

- `days`：路径参数，`1d` / `3d`（最多 3 天）
- `type`：必选，指数类型 ID，逗号分隔可多选（如 `type=3,5`）；`0` 表示全部（选 `0` 时不能再选其他）
- `location`：LocationID 或 `经度,纬度`（十进制，最多两位小数），如 `101010100` / `116.41,39.92`

响应 `daily[]`：`date`、`type`、`name`、`level`（等级）、`category`（级别名称）、`text`（详细描述，可能为空）。
