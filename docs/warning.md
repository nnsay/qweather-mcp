# 预警 (Weather Alert)

来源: https://dev.qweather.com/docs/api/warning/

提供全球官方发布的极端天气预警，覆盖全球大部分国家/地区，含数百种预警事件。预警详情、严重等级、紧迫程度、确定性、防御指南、颜色、触发条件、生效与过期时间。

## 实时天气预警

https://dev.qweather.com/docs/api/warning/weather-alert/

```
GET /weatheralert/v1/current/{latitude}/{longitude}?localTime=false
```

参数：经纬度路径参数（最多两位小数）；`localTime` `false` UTC（默认）/ `true` 本地时间。

响应：`metadata.zeroResult`（`true` 表示请求成功但无预警）+ `alerts[]`。

## 预警字段（alerts[]）

| 字段 | 含义 |
| --- | --- |
| `id` | 预警唯一标识 |
| `senderName` | 发布机构名称，可能为空 |
| `issuedTime` | 原始预警信息生成时间 |
| `messageType.code` | 信息性质：`alert` / `update` / `cancel` |
| `messageType.supersedes` | 本条取代的之前预警 ID 列表 |
| `eventType.code` / `eventType.name` | 事件代码 / 名称 |
| `urgency` | 紧迫程度，可能为空 |
| `severity` | 严重程度 |
| `certainty` | 确定性，可能为空 |
| `icon` | 图标代码 |
| `color.code` + RGBA | 颜色代码与颜色分量 |
| `effectiveTime` | 生效时间 |
| `onsetTime` | 事件预计开始时间，可能为空 |
| `expireTime` | 失效时间 |
| `headline` | 简要描述/标题 |
| `description` | 详细描述 |
| `criteria` | 触发标准，仅供参考，可能滞后 |
| `responseTypes` | 应对方式类型代码，可能为空 |
| `instruction` | 防御指南，可能为空 |

### 枚举值

- `messageType.code`：`alert` 初始活跃；`update` 更新并取代 `supersedes`；`cancel` 取消 `supersedes`，有效期 1 小时
- `urgency`：`immediate` 立刻行动 / `expected` 尽快（通常 1 小时内）/ `future` 近期行动 / `past` 已不再发生 / `unknown`
- `severity`：`unknown` / `minor` 威胁极小 / `moderate` 可能构成威胁 / `severe` 重大威胁 / `extreme` 严重威胁
- `certainty`：`observed` 已/正发生 / `likely` ≥50% / `possible` ≤50% / `unlikely` 接近 0 / `unknown`
- `color.code`：`white` / `gray` / `green` / `blue` / `yellow` / `amber` / `orange` / `red` / `purple` / `black`

### 时间字段语义

- `issuedTime` 发布时间：机构创建/发出本条信息的时间，不代表天气开始或预警生效
- `effectiveTime` 生效时间：本条信息开始适用
- `onsetTime` 事件开始时间：极端天气**预计**开始（预报值，可能偏早/偏晚）
- `expireTime` 过期时间：本条信息预计失效

时间无强制先后顺序（天气已发生时，发布可晚于事件开始）。失效判定：API 不再返回 / 被更新 / 被取消 / 超过过期时间。

## 预警的变更（alert-changes）

https://dev.qweather.com/docs/api/warning/alert-changes/

预警非静态对象，随天气发展可能多次更新。用 `messageType.code` 判断：`alert` 首次发布 / `update` 更新（等级、范围、过期时间等）/ `cancel` 主动取消（有效期 1 小时）。被 `update`/`cancel` 取代的旧预警在 API 中不再返回。

示例：`A`(alert, minor, 18:00) → `B`(update, supersedes [A], moderate, 20:00) → `C`(cancel, supersedes [B], 16:00)。
